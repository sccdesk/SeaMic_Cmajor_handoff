AUDIO INPUT

Choose microphone

Select a microphone before starting the engine. Device names may require microphone permission.

Every DSP module starts bypassed. Use the per-module controls or activate the full chain. Parameter sliders send changes to Cmajor immediately, even while a module is bypassed; activate that module to hear the result. The Noise Gate / VAD is marked “POR REHACER” and stays bypassed while it is rebuilt. AEC stays bypassed until a playback reference is connected; to exercise it, connect the application playback with SeaMicAudio.connectPlaybackSource(node) so its echo reaches the microphone. Use headphones.
