5.2 Stage-by-stage design

(a) DC block

First-order high-pass, y[n] = x[n] − x[n−1] + R·y[n−1], with R = 1 − 2π·20 Hz/fs clamped to [0.9, 0.9995]. Removing DC matters twice: it stops the integrators downstream from riding a bias, and it protects the K-weighting mean-square from a non-audible offset that would still consume headroom. Implemented rate-agnostically (R7).

(b) K-weighting (perception model)

Two cascaded DF1 biquads — the BS.1770 shelf (+3.985 dB, f0=1681.974 Hz, S=0.7071) and a 60 Hz Q=0.5 high-pass — with coefficients computed from processor.frequency on the first frame using RBJ closed forms (§2.2). State: four delay elements per stage. Used only by the sidechain; the audio path stays bit-exact with the input apart from intentional gain.

(c) VAD — the hard component

Figure 3 is the state diagram of the final VAD. Its estimator (Figure 4) maintains a 32 ms rectangular RMS window over a circular buffer, reduces it into 1 s sub-block minima, and takes the lower-only minimum over a 3 s sliding window; bootstrapping for the first 0.25 s uses an instant-minimum track from the −40 dBFS cap. Decision: enter at SNR > 9 dB (oor absolute level for safety), exit at SNR < 4 dB after 600 ms hangover, plus the flatness override (1.5 s grace, then 600 ms below 3 dB crest).
