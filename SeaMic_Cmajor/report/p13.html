M8 — Render-engine quirks and performance warnings Symptom 1. Every render — including an unconditional beep that ignores its input — is digital black for ≈ 1.0–1.15 s at the start of the input file.
Diagnosis. Input-independent blackness proves it is not DSP: cmaj render --input warm-up. Policy adopted: ignore seg0 in all render analyses; never attribute engine behaviour to user code without an input-independent control (the pass-probe).
Symptom 2. Compiler warnings: array index of type 'int' … runtime range check … use .wrap<> or .at() on ring buffers.
Fix. ring.at(pos)-style access; warnings eliminated, all patches load clean.
