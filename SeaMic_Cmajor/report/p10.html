(d) AGC

Feed-forward servo on the K-weighted 32 ms RMS. Error in dB drives the gain with asymmetric coefficients (80 ms down / 1.5 s up), clamped to [+30, −12] dB, updated only while the VAD flag is set, plus a speechSeen latch that prevents any adaptation before the first detected utterance. The applied linear gain is smoothed per-sample (10 ms toward lower gain, 50 ms toward higher) to avoid zipper noise.

(e) Soft gate

Downward expander driven by the VAD: target attenuation 0 dB on speech, 10 dB on silence, 10 ms close / 150 ms release, initialised closed (10 dB) so no pre-roll noise is emitted before the first detection, and holding open 400 ms past each VAD exit (holdExtraTime) — the explicit "longer hold" delivered on the stakeholder's request.

(f) Look-ahead limiter

64-sample delay line, peak follower on the undelayed input (instant attack, 80 ms release), gain = min(1, 0.891/peak) applied to the delayed sample. Per-sample guarantee, no windowing (§2.6).
