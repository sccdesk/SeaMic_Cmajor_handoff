# SeaMic Project Memory

- **Web:** Internal vertical DSP console showing ADC → seven independent DSP modules → Output → Opus → Network. All user-facing console text and active project documentation are in English.
- **Module patches:** The browser loads standalone patches in series: `SeaMicDCOffset` → `SeaMicAEC` → `SeaMicDeReverb` → `SeaMicNoiseGateVAD` → `SeaMicLoudnessNormalization` → `SeaMicToneWarmth` → `SeaMicLookAheadLimiter`. Each has its own generated WebAudio runtime and GUI.
- **Composite harness:** `SeaMicDSPChain.cmajorpatch` remains for direct CLI testing only; the browser does not load it. Do not call it a DSP module.
- **Bypass:** ON means bypassed/dry pass-through; OFF means active processing. Each switch shows the effective state and the action it will take. Every module starts bypassed; the browser starts with reduced-level dry microphone monitoring.
- **Solo:** One DSP stage is activated with all other stages bypassed; leaving Solo restores the previous chain and module states. VAD Solo tests its detector with transparent audio. Tone Solo enables the post-tone DC blocker. AEC activation and Solo unlock only while an application playback source is connected through the live playback bus.
- **AEC playback bus:** `window.SeaMicAudio.start(appAudioContext)` can run the DSP host in the application's existing context; `connectPlaybackSource(node)` routes that live AudioNode to both speakers and AEC's pre-output reference. Nodes must use this same context; the returned disposer disconnects the source. Disconnecting the final source forces AEC into bypass. Stopping the DSP host leaves a shared app context and its speaker route running. No system loopback or offline file player is used.
- **AEC delay coverage:** The current NLMS filter defaults to 512 taps with a 1024-tap maximum. Echo-path time coverage is taps/sample-rate (32 ms default at 16 kHz, about 10.7 ms at 48 kHz); the host warns when the context differs from the 16 kHz target. Do not increase filter size without acoustic-path and CPU measurements.
- **Meters:** Input and output have scrolling peak-envelope waveform views showing the latest five seconds in 50 ms buckets; numeric dBFS peak readouts and bar meters remain in place. The analyser window is 1024 samples.
- **Independent stage routing:** DC Offset Removal processes microphone and playback-reference streams; AEC receives both. Noise Gate/VAD outputs audio plus a speech flag, which feeds Loudness Normalisation's AGC sidechain. Tone/Warmth includes the post-tone DC blocker.
- **Target chain:** ADC → DC Offset → AEC → De-Reverb → Noise Gate/VAD → Loudness Normalisation → Tone/Warmth → Look-Ahead Limiter → Output. Opus and Network are not integrated.
- **Current limitations:** VAD uses RMS/noise-floor tracking with SNR hysteresis, not Otsu bimodality. Tone uses an asymmetric rational shaper without a shelf. AGC is not a full integrated EBU R128 meter. Real AEC performance still requires the integrated application's live playback node and acoustic-path testing.
- **De-Reverb stability:** De-Reverb now caps gain at unity, limits attenuation to 6 dB, and smooths gain reduction/recovery over 20/120 ms (instead of 5 ms symmetric smoothing and -12/+3 dB range) to reduce rapid gain modulation.
- **VAD word-tail handling:** VAD close hangover (400 ms default), gate hold (150 ms default), gate depth (30 dB default), and both SNR thresholds (enter 9 dB / exit 4 dB defaults) are `input event float32` endpoints hoisted through the `SeaMicNoiseGateVAD` graph and adjustable in real time from the console GUI; each event clamps to its annotation range and member defaults match the `init` annotations, so headless renders stay safe (no value-endpoint zeroing like mistake M2). SoftGate fades down over 30 ms and initializes open. Removed the redundant secondary 1.5 s + 600 ms forced-close path. VAD also closes after sustained RMS below -60 dBFS as a guard against a noise-floor estimate that remains too low after near-silence. Both VAD and AGC clamp their sliding squared-sample sums at zero against floating-point roundoff. Verify the fixed quiet-level threshold against actual microphone levels before tuning it.
- **AGC stability:** Clamp the rolling squared-sample sum to zero before calculating RMS; floating-point roundoff can otherwise make it slightly negative, produce NaN gain state, and silence Loudness and downstream Tone. This is a numerical guard, not an acoustic parameter change.
- **AEC host integration:** The host now provides `SeaMicAudio.start(appAudioContext)` and `connectPlaybackSource(node)`. A live same-context playback node feeds both speakers and the pre-output AEC reference; AEC activation/Solo unlock only while the bus has a source, and losing the last source forces bypass. The AEC patch's redundant internal DC-filter control is hidden and held bypassed because stage 1 owns DC removal.
- **Runtime:** Official Cmajor-generated bundles live in `web/generated/<patch-name>/`. Never hand-edit generated bundles or files in `web/cmajor-runtime/`; regenerate each affected patch with the Cmajor CLI.
- **HTTP:** Required for generated ES modules, AudioWorklet, and WebAssembly. Do not open the Cmajor console using `file://`.
- **Legacy:** The original legacy AEC implementation remains untouched.
- **Verification:** The seven standalone patches compiled with Cmajor 1.0.3209; the three existing AEC tests passed. Browser testing loaded all seven generated patches and GUIs, exercised chain activation, bypass, Solo, and Stop, and verified that the AEC controls unlock on playback-node connection, enter Solo, then relock and bypass on disconnection. A shared application AudioContext remained running with its playback route after stopping the DSP host. Prior synthetic-input tests verified dry/DSP audio and Loudness/Tone recovery after silence; no real microphone was opened.
- **Next:** Integrate the SeaTime live playback node using the documented `SeaMicAudio` hook, then evaluate AEC convergence and double-talk with the application's real acoustic path. Do not open a real microphone without explicit permission.
- **Invariant:** Do not change established VAD/AGC acoustic parameters without measurements and authorization.
